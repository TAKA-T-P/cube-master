# CUBE MASTER（仮）

立方体をテーマにした算数・数学の学習 Web アプリです（対象：小学4年生〜中学3年生）。
立方体の展開図・切断・位置関係・サイコロの回転・体積などの空間図形問題を扱う予定です。

公開ページ：https://taka-t-p.github.io/cube-master/

**現在は Phase 6（Ver.0.7.0）**：Phase 0〜5 で作った、6カテゴリ・51種類の問題テンプレート、3D 演出、
通常トレーニング・1分チャレンジ・100秒の段位認定（21段階）・ヒント・復習・学習記録を、使いやすさ・安定性・品質の面から仕上げました
（プレイ形式の見分けやすさ、時間切れの扱い、演出の速さの一元管理、効果音のオン／オフと音量、タブ式のあそびかた、全テンプレートの総点検）。
新しい問題カテゴリ・テンプレートは増やしていません。

- 技術：HTML / CSS / JavaScript（ES Modules）、Vite、Three.js（OrbitControls・Raycaster・CSS2DRenderer）、Vitest
- サーバー・データベース不要の静的サイト（GitHub Pages で公開）
- UI フレームワーク・TypeScript は不使用。外部 CDN にも依存しません

## 動作環境

- Node.js 22.12 以上（推奨：24 LTS。`.nvmrc` 参照）
- WebGL2 に対応したブラウザ（Chrome / Edge / Safari / Firefox の最新版）
  - WebGL2 が使えない端末でも、トレーニングは問題文・図・選択肢だけで回答できます

### トレーニング

1. **カテゴリ選択**：10 カテゴリを名前だけの小さなボタンで表示。遊べるのは「①展開図と頂点・辺」「③位置関係」「④展開図パズル」「⑥サイコロ・回転」「⑦立方体の個数・着色」「⑩積み木の見え方・投影図」（ほかは準備中）。
   ボタンを押すと、画面下（固定）に説明と「次へ」が出ます（対象学年は表示しません）。右上の「学習記録」で記録を見られます
2. **設定**：難易度（基本／標準／応用／すべて）と、出題のしかた（「問題数を選ぶ」「1分チャレンジ」を同じ行に横並び）
   - 問題数を選ぶ：問題数のスライダー（1〜20問。初期値は5問）。タイマーなし
   - 1分チャレンジ：スライダーの代わりに、選んだ難易度の最高記録（「最高記録：7問正解」）を表示。1分間で何問正解できるかに挑戦します。
     不正解（おしいをふくむ）は残り時間 −10秒。カウントダウン・タイマー・答え合わせの間は時間が止まる仕組み・中断の扱いは段位認定と同じで、ヒント・パスはありません。
     結果画面に正解数・自己ベスト更新・回答数・正答率を表示し、間違えた問題を復習できます。最高記録は難易度（基本・標準・応用・すべて）ごとに学習記録へ保存します（通常の累計には入れません）
3. **問題**：問題文を読み、選択肢から答えて「回答する」。回答すると、同じ位置のボタンが「次の問題へ」（最後の問題では「結果を見る」）に変わります
   - 問題の基準になる辺・面は **オレンジ** で表示され、正解表示中も消えません（位置関係）
   - 位置関係では立方体を自由に回せます（面は半透明で表示。「面を不透明に」で切り替え）。回答は選択肢ボタンで行います
   - サイコロ・積み木・展開図では、答えが見えてしまわないように **回答するまで 3D を表示しません**。
     展開図の問題では、3D の場所に展開図（点・辺・面のラベルつき）を表示し、回答すると 3D の展開図が折りたたまれて立方体になります。
     積み木の問題では、3D の場所に静的な見取図（見る向きを示す赤い矢印つき。矢印の根元が見る人の場所）を表示し、回答すると同じ場所が 3D に切りかわります。
     サイコロの問題文の下には、はじめの向きの見取図（「上・前・右」の向きつき）と回転の手順（番号・矢印・文字）を表示します。
     回答すると、自由に回せる立方体が現れて正解演出が始まります
   - ふつうのサイコロ（向かい合う面の目の和が7）の面は数字ではなく **目（ドット）** で表示します（1の目は大きな赤い目）。
     和が7ではない配置のサイコロは、目の代わりに **マーク（〇◎×●◇◆）** で表示します。答えの選択肢も面の絵で表示します
   - 図を選ぶ問題では、選択肢に見取図や面の図（ア〜エ）を表示します
   - 「すべて選ぼう」の問題はチェック形式、「1つ選ぼう」の問題はラジオ形式
   - **ヒント**：回答前に「ヒントを見る」で、考え方の手がかりを表示します（答えは出しません。何度見ても同じ内容）。
     ヒントを使っても正誤判定・正答率は変わりません（使ったかどうかは学習記録に残します）
   - 小立方体の問題では、3D の場所に静的な見取図（分割線・色を塗った面・取り除いた小立方体の赤い点線）を表示し、回答すると 3D に切りかわります
   - 積み木の個数の問題では、3D の場所に積み木の見取図（B12 は「今の形 → 完成形」の2つ）を表示します
4. **解答・解説**：「正解！」「おしい！」「不正解」と解説を表示
   - 3D では、誤って選んだ要素が **赤**、正解の要素が **緑** で1つずつ光ります
   - サイコロでは立方体が実際に回転し、積み木ではカメラが矢印の方向（正面・右・真上など）へ移動して答えを確かめられます
   - 回答すると「○」「△」「×」が効果音とともに約1秒大きく出て、そのあと解説を表示します（タップですぐ閉じる）
   - 小立方体では、境界線が現れて小立方体に分かれ、少しはなれてから、条件に合う小立方体が緑の輪郭（ほかは半透明）で光り、個数を表示します。
     「元に戻す」「分離して見る」で切りかえられます
   - 積み木の個数では、積み木が下の段から順に持ち上がって段ごとに分かれ、各段の個数（「1段目 6個」）と合計を表示します。
     見えない積み木は、ほかを半透明にして色付きで示します。指定した段は緑で持ち上げて1個ずつ数え、完成形の問題では加える積み木が1つずつ置かれます
   - 3D の下の「もう一度見る」でリプレイ、「スキップ」で演出を飛ばせます
   - 「おしい！」は正解・不正解のちがいが1つだけのとき。正答率には完全正解だけを数えます
5. **結果**（見出しは「トレーニング結果」）：正解数・正答率・カテゴリ・難易度。その下に「もう一度挑戦」「設定を変更」「カテゴリ選択」「タイトルへ」（2行×2列）、「第◯問」のカード、「間違えた問題を復習」
   - 「やめる」は確認のうえ、回答済みの分の結果を表示します
   - 「第◯問」のカードを押すと、その問題を1問だけ解き直せます
6. **復習**：「間違えた問題を復習（N問）」で、不正解・おしいだった問題を **同じ問題（同じ図・条件・正解・選択肢の並び）** のまま解き直します（0問ならボタンを出しません）
   - 終わると「復習の結果」（復習した問題数・正解できた数・復習の正答率）を表示。まだ間違えている問題があれば、続けて復習できます
   - 復習の結果は、もとのトレーニングの結果（正解数・正答率・学習記録の累計）には入れません
7. **学習記録**：カテゴリ別に累計問題数・累計正解数・正答率・練習回数・ヒントの回数・難易度別の正答率・最近の結果・復習待ちの問題数を表示します
   - 未プレイのカテゴリは「まだ記録がありません」
   - 間違えた問題はブラウザに保存され、後日「復習する」で同じ問題を復習できます（正しく解けた問題は復習待ちから外れます）
   - 「学習記録を消去」（学習記録画面・あそびかた）で、確認のうえ CUBE MASTER の保存データだけを消せます

### 3つのプレイ形式

| プレイ形式 | 入り口 | 特徴 | 上の帯の表示 |
|---|---|---|---|
| 通常トレーニング | トレーニング → 設定で「問題数を選ぶ」 | 問題数を選ぶ・時間制限なし・ヒントあり・解説と3Dを自由に見直せる | 「トレーニング」 |
| 1分チャレンジ | トレーニング → 設定で「1分チャレンジ」 | 1カテゴリ・60秒・正解数を競う・不正解 −10秒・ヒントとパスなし | 「1分チャレンジ・基本」など |
| 段位認定 | トップの「段位認定」 | 6カテゴリ混合・100秒・得点で段位・パスあり | 「段位認定・スタンダード」など |

- 設定画面の「問題数を選ぶ」は「時間を気にせず、じっくり練習！」、「1分チャレンジ」は「60秒で何問正解できるか挑戦！」と表示します
- 1分チャレンジ・段位認定は同じ時間制の画面（`ui/timedPlayScreen.js`）で、カウントダウン・タイマー・答え合わせの間の停止・自動で次の問題へ・TIME UP!・中断の扱いがそろっています。
  時間切れの瞬間に、選択肢・「回答する」・「パス」を押せなくします
- 演出の速さは `src/core/revealSettings.js` で一元管理します（トレーニング：ふつうの速さ・「○△×」約1秒／時間制の2モード：2.5倍速・長くても約3.2秒で最終状態・「○△×」約0.5秒）。
  どの演出も途中の動きは省かず、スキップでは最終状態を表示します。演出の間はタイマーが止まるので、演出の長さで考える時間は変わりません

### 効果音の設定

- トップ画面の右上の小さなスピーカーのアイコン（押すとオン／オフ）と、あそびかたの「記録と設定」タブで、オン／オフと音量（0〜10）を変えられます。設定はブラウザに保存します（キー `cubeMaster:settings`）
- ボタンを押すと「ポッ」という低く短い音が鳴ります（`installButtonSound`。無効なボタンと、すぐあとに正誤の音が鳴る「回答する」では鳴りません。「次の問題へ」などでは鳴ります）
- トップ画面のメニューは2行×2列（トレーニング・段位認定／3D立方体をためす・あそびかた）で、いちばん下に小さく著作権表示「©2026 T.TAKEMOTO / KEC Glows」を入れています
- オフのときは何も鳴らしません。効果音がなくても、○△×・色・文字で正誤と結果がわかります。Web Audio が使えないブラウザでも、そのまま遊べます

### 段位認定（100秒）

「100秒で何問解ける？立方体マスターを目指せ！」。トレーニングで習得した力を、短い時間で試すゲームモードです。

| 項目 | トレーニング | 段位認定 |
|---|---|---|
| 制限時間 | なし | 100秒（回答できる時間だけ数える） |
| 出題 | カテゴリ別 | 6カテゴリを混ぜて出題 |
| 難易度 | 自由に選ぶ | レベルごとに決まっている |
| ヒント・もう一度見る | あり | なし |
| 解説・3D 演出 | じっくり | 短く・速く再生して自動で次の問題へ |
| 成績 | 正答率 | スコア・段位（レベル別） |

1. **レベル選択**：ベーシック（★1）・スタンダード（★1 約30%・★2 約70%）・エキスパート（★2 約30%・★3 約70%）。レベルのボタンのすぐ下に「スタート」
2. **3・2・1・START!**：表示に合わせて効果音（3・2・1 はピッ、START! はピーン）。この間は問題が見えないように画面全体をおおい、タイマーは動きません
3. **100秒チャレンジ**：画面の上にタイマー（「72.4秒」）・得点・連続正解数を表示。残り10秒で色が変わり、残り5秒で大きなカウントダウン
   - 回答を確定するとタイマーが止まり、「○△×」（約0.5秒）→ 正誤と得点（「+160点」「−50点」「残り時間 +3秒」）→ 3D 演出（2.5倍速。途中の動きは省かない。長くても約3秒で最終状態）→ 自動で次の問題へ。
     次の問題が表示されて回答できるようになった時点でタイマーが再開します（「次の問題へ」で早く進むこともできます）
   - **パス**：「回答する」と同じ行の左の「パス」で問題を入れかえられます。「問題を入れかえますか？ ペナルティ：残り時間 −○秒」の確認で「はい」を押すと次の問題へ。
     n 回目のパスで残り時間が 2×n 秒へります（確認の表示中も時間は減り続ける）。パスは回答の数・正答率に入らず、減点もしませんが、連続正解ボーナスは0に戻ります
   - ヒント・もう一度見る・展開図に戻すなどの自由な観察はできません。くわしい解説は結果画面から復習できます
   - 0秒になると「TIME UP！」。回答中だった問題は未回答（正解にも不正解にも数えない）。制限時間を過ぎてから確定した回答は数えません
4. **結果発表**（「TIME UP！」はプレイ画面の最後にだけ出し、結果画面には出さない）：得点のカウントアップ → 正解数・正答率・最大連続正解・誤答の減点・多答問題ボーナス・パスの回数・平均解答時間・カテゴリ別の正解数 → 段位（「五段＋ 認定！」「十段★ 達成！」）。
   最高段位が上がったときだけ昇段の演出（初段・十段・皆伝は少し豪華に）。最高得点の更新は「自己ベスト更新！」。画面をタップすると演出をとばせます。
   「正解数」のすぐ上に「もう一度挑戦」「レベルを変更」「記録を見る」「タイトルへ」（2行×2列）。下に「間違えた問題を復習」（トレーニングと同じ画面でじっくり解き直す）
5. **中断**：「やめる」・ほかのタブへの切りかえ・画面を離れる（戻る操作など）と中断になり、記録に残りません（同じ挑戦は再開できません）

#### スコアと段位（`src/core/certificationRules.js` で一元管理）

- 完全正解：★1 100点・★2 160点・★3 240点
- 誤答（不正解・部分正解）は減点：n 回目の誤答で 50×n 点（n は6まで。1回目 50点・2回目 100点…6回目以降 300点）。まちがえるほど重くなります。得点は0点より下がりません。残り時間は減りません
- 答えが複数ある問題（多答問題）に一発で正解すると、残り時間が +3秒
- 連続正解ボーナス：3〜4問連続は1問につき +20点、5問以上は +40点。不正解・部分正解で連続は0に戻る
- 段位は 21 段階（10級 → … → 1級 → 初段 → 二段 → … → 十段 → 皆伝）。内部では 1〜21 の整数（`rankLevel`。0 は認定なし）で、数が大きいほど上位
- 表記はレベルごとに、ベーシックは段位名のみ（五段）、スタンダードは「＋」（五段＋）、エキスパートは「★」（五段★）を直後に付けます（皆伝・皆伝＋・皆伝★）
- 必要スコア（仮の基準。プレイテストのあとに調整する）。ベーシック・スタンダード・エキスパートで共通、2500点で最高段位（皆伝）

| 段位 | 必要スコア |
|---|---:|
| 10級〜1級 | 100〜1,000（100点ごと） |
| 初段・二段・三段 | 1,100・1,200・1,300 |
| 四段〜十段 | 1,450〜2,350（150点ごと） |
| 皆伝 | 2,500 |

  （21段階すべての値は `certificationRules.js`。今の基準は `rulesVersion: 3`）
- 基準を変えるときは `CERTIFICATION_RULES.rulesVersion` を上げます。記録は基準ごとに分けられ、前の基準の最高記録は「前の基準での最高記録」として残ります
- 問題ごとの考える時間の目安（`recommendedSeconds`）・段位認定で出さないテンプレート（`excludedTemplates`）・出題するカテゴリ（`categories`）も同じ設定で変えられます

#### 出題と 100 秒タイマー

- 出題（`src/core/certificationSession.js`）：カテゴリ × 難易度ごとに既存の `QuestionPicker` を使うので、問題の生成と数学的な確かめはトレーニングと同じです。
  カテゴリはなるべく均等に（出題の少ないカテゴリから）、同じカテゴリは3問以上続けず、同じテンプレートも続けません。難易度はレベルの割合に近くなるように選びます。
  問題を作れなかったときは、ほかのカテゴリで作り直します（タイマーは止まっているので時間は減りません）
- タイマー（`src/core/certificationTimer.js`）：`performance.now()` の差から「回答できた時間」だけを足していきます。画面の表示は0.1秒ごとに更新するだけで、時間の計算には使いません。
  `start` `pause` `resume` `stop` `addTime`（多答問題のボーナス）`penalize`。二重に止める・再開しても時間はずれません
- 記録（`src/core/certificationRecords.js`。キー `cubeMaster:certification`）：レベルごとに挑戦回数・最高得点・最高正解数・最高段位・最後に挑戦した日時・最近の結果（20件）。
  トレーニングの学習記録（`cubeMaster:history`）とは別に保存するので、段位認定をしてもトレーニングの記録は変わらず、古い保存データもそのまま読めます。
  最高段位・最高得点は、低い成績で下がりません

### 画面のレイアウト

- スマホ縦画面では、3D の立方体を画面の上に固定し、その下のメニュー（問題文・図・選択肢・解説、プレビューの操作パネル）だけがスクロールします
- PC・タブレット横画面では、3D を左、メニューを右に並べ、右側だけがスクロールします
- 選択肢やボタンは高さを詰め（最小の高さ 31px）、一画面に多く表示できるようにしています

### 3D 立方体の操作

| 操作 | パソコン | スマホ・タブレット |
|---|---|---|
| 回転（カメラが立方体のまわりを回る） | ドラッグ | 1本指でなぞる |

- **復習**：`TrainingSession` に出題した問題データそのもの（`questions` オプション）を渡して解き直します。ランダムに作り直さないので、別の問題になりません
- **保存**（`localStorage`。キーはすべて `cubeMaster:` で始まる）
  - `cubeMaster:history`：カテゴリ別の学習記録（`src/core/learningHistory.js`。`version: 1`）
  - `cubeMaster:review`：間違えた問題（`src/core/reviewManager.js`。1件ごとに `schemaVersion`・`category`・`templateId`・`problemKey`・問題データ・`lastIncorrectAt`・`incorrectCount`）
  - 個人情報（名前・ID）は保存しません。保存数はカテゴリごと15問・全体60問・約1.2MB まで（古いものから消す）
  - 読み込むときは必ず形を確かめ、こわれた値は直すか捨てます。問題の `schemaVersion`（`QUESTION_SCHEMA_VERSION`）が今とちがう・データが不正・テンプレートがなくなった問題は、作り直さずに除外します
  - `localStorage` が使えない環境（プライベートモードなど）でも練習でき、記録はページを閉じるまでメモリに残ります。保存に失敗したときは1度だけお知らせを出します

## 展開図の数学エンジン

- **格子データ**（`src/core/cubeNet.js`）：展開図は整数格子上のマス `{ id, x, y }` の集まり（x は右、y は下）。
  回転・裏返し・平行移動、となり合うマス、外周の辺・点、種類のキー（`getCanonicalNetKey`）。問題で表示する向きやセル ID は変えない
- **11種類**（`src/core/cubeNetCatalog.js`）：6マスのつながった図形（35種類）をすべて作り、折りたたんで立方体になるもの（11種類：1-4-1型6・1-3-2型3・2-2-2型1・3-3型1）を登録。
  手で書いた一覧に頼らないので、どんな 6 マスの図形でも同じ方法で判定できる
- **折りたたみ**（`src/core/cubeNetFolding.js`）：基準のマスを上面に置き、となりのマスを共有辺を軸に 90° ずつ下へ折る（BFS）。
  整数ベクトルだけで計算し、面の重なり・辺の食いちがい・マスの数・つながり・位置の重複を検出して、理由と問題のマスを返す
- **3D**（`src/three/cubeNetModel.js`）：マスごとのパネルを折る順番の木どおりに入れ子にし、共有辺に置いたちょうつがいを軸に回す（紙を折るように動く）。
  奥のマスから順に折り、平らなときは展開図全体が見える大きさ、立方体になるにつれて元の大きさへ。逆再生で展開図に正確に戻る
- 2D の展開図・折りたたみ計算・3D モデルは、すべて同じマスのデータから作ります

### 回転の定義（`src/core/cubeRotations.js`）

| ID | 言い方 | 動き |
|---|---|---|
| `right` | 右へ転がす | 元の上面が右側面になる |
| `left` | 左へ転がす | 元の上面が左側面になる |
| `forward` | 前（手前）へ転がす | 元の上面が前面になる（手前 = +Z） |
| `backward` | 後ろ（奥）へ転がす | 元の上面が後面になる |
| `turnRight` | 水平に右へ回す | 元の前面が右側面になる（上下は変わらない） |
| `turnLeft` | 水平に左へ回す | 元の前面が左側面になる |

回転は成分が -1・0・1 の整数行列で計算するので、何回回しても誤差がたまりません。
立方体の向き（`{ top: 'ABCD', front: 'ABFE', … }`）は 24 通りで、面 ID は回転しても変わりません（変わるのは各面が向いている方向）。
カメラの回転（観察の視点）と、立方体そのものの回転は別々に管理しています。

## 座標系と立方体の定義

Three.js の右手系。X = 左右、Y = 上下、Z = 奥行き（+Z が手前）。中心は原点、一辺は 2。

| 頂点 | 座標 | | 頂点 | 座標 |
|---|---|---|---|---|
| A | (-1, +1, +1) | | E | (-1, -1, +1) |
| B | (+1, +1, +1) | | F | (+1, -1, +1) |
| C | (+1, +1, -1) | | G | (+1, -1, -1) |
| D | (-1, +1, -1) | | H | (-1, -1, -1) |

上面が ABCD、底面が EFGH（A の真下が E、B の真下が F、C の真下が G、D の真下が H）。

- 辺（12）：AB, BC, CD, DA, EF, FG, GH, HE, AE, BF, CG, DH
- 面（6）：ABCD(+Y・上), EFGH(-Y・下), ABFE(+Z・前), BCGF(+X・右), CDHG(-Z・後ろ), DAEH(-X・左)

ID は表記ゆれを正規化して扱います（`"BA"` → 辺 `AB`、`"FGCB"` → 面 `BCGF`）。
存在しない ID（`"AC"` など）は `CubeElementError` になります。

### 確認状況・既知の問題（Ver.0.7.0）

- **実機・ブラウザでの確認**：開発環境ではヘッドレスブラウザが使えないため、Chrome・Edge・Android Chrome・iPhone Safari・iPad Safari での動作は **未検証** です（上の手動確認項目を実機で確認してください）。
  見取図の SVG の一部は画像に変換して形を確かめています
- **メモリ・描画**：画面を移るたびに 3D を作り直し、そのたびに WebGL のコンテキストを返すようにしました（`renderer.forceContextLoss`）。描画は必要なときだけ行い（`requestRender`）、
  画面の大きさの監視・イベントは画面を閉じるときに外します。ただし、長時間の連続プレイでのメモリ使用量は実機で測っていません
- **難易度・配点・段位基準**：仕様どおり、推測では変えていません。実際の生徒の解答時間・得点分布が集まってから調整します（変えるときは `rulesVersion` を上げる）
- **アニメーション軽減**：OS の「視差効果を減らす」設定では、○△×・昇段などの画面の動きを止めます。3D の演出は短縮再生のまま（軽減設定での 3D の扱いは未対応）

## 後続 Phase で使う API

### 問題データの形（カテゴリ共通。`src/core/questionSchema.js`）

```js
{
  id, templateId: 'P01', key: 'P01:AB', category: 'position', difficulty: 1, type: 'multiple',
  question: '辺ABと平行な辺をすべて選びなさい。',
  scene: { model: 'cube', referenceElements: ['AB'], cameraPreset: 'default' },
  choices: [{ id: 'CD', label: '辺CD', elementId: 'CD' }, { id: 'none', label: 'あてはまる面はない', fixed: true }],
  correctAnswers: ['CD', 'EF', 'GH'],
  explanation: { text: '…', highlightElements: ['CD', 'EF', 'GH'], animation: 'highlightElements' },
}
```

- 選択肢の `id` は任意の文字列（サイコロの目・形の名前・分数などでもよい）。正誤は選択肢 ID の集合で比較する
- `elementId` は 3D 上で対応する要素（誤選択を赤く表示するのに使う）。文章の選択肢では省略
- `fixed: true` の選択肢はシャッフルせず末尾に置く
- Phase 2 で追加（省略可）：`scene.model`（`'cube'`・`'dice'`・`'colorCube'`）、`scene.faces`（面 ID → 装飾）、
  `scene.orientation`（はじめの向き）、`scene.showLabels`、`scene.interaction`（回答前後の回転・ズームの可否）、
  `visuals`（問題の図）、`choices[].visual`（選択肢の図）、`choices[].labelByPosition`（ア〜エを並び順で付ける）、
  `explanation.reveal.steps`（`{ type: 'rotate', moves }`・`{ type: 'camera', direction }`・`{ type: 'pause', ms }`）
- Phase 4 で追加（積み木の個数）：`scene.counting`、図の種類 `blocksPair`（`items`。`fitTo` で2つの図の小立方体を同じ大きさに）、
  演出 `{ type: 'countLayers', hidden }`・`{ type: 'countLayer', level, cubes }`・`{ type: 'addBlocks', cubes }`
- Phase 4 で追加：`scene.model: 'subcubes'`・`scene.subcubes`（`{ divisions, paintedFaces, removed }`）、図の種類 `subcubes`、
  演出 `{ type: 'divide' }`・`{ type: 'separate', to }`・`{ type: 'highlightSubcubes', cubes, label }`、`hint: { text }`、`QUESTION_SCHEMA_VERSION`
- Phase 3 で追加：`scene.model: 'net'`・`scene.net`（3D で折りたたむ展開図）・`scene.preview`（回答前に 3D の場所へ出す図）、
  図の種類 `net`、演出 `{ type: 'fold', to }`、`{ type: 'highlightBlocks', cubes }`、解説の `〔choice:ID〕`

### 段位認定（`src/core/certificationSession.js` ほか）


| 破棄 | `dispose()` |

強調のレイヤーは `reference`（基準・オレンジ）`default`（解説・緑）`wrong`（誤選択・赤）`correct`（正解・緑）。
同じ要素が複数レイヤーにあるときは **correct > wrong > default > reference** の1つだけを表示し、上位を消すと下位の表示に戻ります。
3D プレビューの選択色（オレンジ `#ff8c1a`）は選択状態の表示で、強調レイヤーとは別管理です。

## 今後の拡張方針

- **新しいカテゴリ**：`src/questions/<category>/` にテンプレートを作り、`questionRegistry.js` の `CATEGORIES` で
  `templates` を設定して `enabled: true` にする。問題画面・エンジン・判定はそのまま使える
- **3D をタップして回答**：`AnswerSelection.toggle(id)` を `viewer.events.on('selection:change')` から呼べば、
  選択肢ボタンと同じ回答状態を共有できる（選択肢 ID に要素 ID を使う問題）
- **展開図・切断**など新しい 3D オブジェクトが必要になったら、`cubeModel` とは別のモジュールで生成し、
  数学データは `core` に置く。問題データの `scene.model` に新しいモデル名を追加する
- **展開図のさらなる活用**（Phase 4 以降）：`foldNet` の各マスの座標（`frames`）を使えば、展開図に描いた目・矢印・線が
  組み立て後にどの向きになるかも計算できる（`cubeFaceLabels` の向きの計算と組み合わせる）。展開図エディタやドラッグ操作にも同じデータが使える
- **切断・内接立体**：展開図と同じく、数学データを `core` に置き、3D モデルを `three` に別モジュールで作る
- 回転アニメーションは `createTurnSequence` / `createQuestionReveal` を使えば、どの問題からでも同じ動きで再生できる
- **Ver.1.0.0 に向けた残課題**
  - 実機（PC の Chrome・Edge、Android、iPhone・iPad の Safari）での総合確認と、長時間プレイでのメモリ・描画の測定
  - プレイテストでの実測（回答数・正答率・平均解答時間・得点分布）と、その結果にもとづく難易度・配点・段位基準の見直し（記録の書き出し・集計のしかたの整備をふくむ）
  - アニメーション軽減設定のときの 3D 演出の扱い、キーボードだけでの操作の確認
  - 準備中の4カテゴリ（切断・内接立体・最短経路・図形の長さと角度）は後続の Phase
- **Phase 6 までの引き継ぎ（調整のしかた）**
  - 段位の必要スコア・得点・ペナルティ・演出の速さは仮の値です。小学生・中学生・講師のプレイテストで、100秒間の回答数・正答率・平均解答時間（結果画面と記録に出る）を見て
    `certificationRules.js` を調整し、`rulesVersion` を上げてください（前の基準の記録は分けて残ります。3レベル共通の基準・★3 240点への変更で `rulesVersion` は 3）
  - 時間がかかりすぎるテンプレートは `excludedTemplates` で段位認定から外せます。`recommendedSeconds` に考える時間の目安を書いておくと、調整・分析に使えます
  - 新しいカテゴリを段位認定に入れるときは `CERTIFICATION_RULES.categories` に加えます（トレーニングで遊べるようにしただけでは入りません）
  - オンラインランキング・対戦・アカウント・クラウド共有は未実装（記録はブラウザの中だけ）。記録の形は `certificationRecords.js`（`RECORDS_VERSION`）
  - 問題データの形を互換性のない形に変えたときは `QUESTION_SCHEMA_VERSION` を上げる（保存済みの復習問題は自動で除外される）
- 立方体の切断・内接立体・最短経路は後続 Phase で実装する
