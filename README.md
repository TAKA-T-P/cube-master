# CUBE MASTER（仮）

立方体をテーマにした算数・数学の学習 Web アプリです（対象：小学4年生〜中学3年生）。
立方体の展開図・切断・位置関係・サイコロの回転・体積などの空間図形問題を扱う予定です。

公開ページ：https://taka-t-p.github.io/cube-master/

**現在は Phase 8（Ver.0.10.0）**：Phase 7 までの8カテゴリ・63種類に、「⑧立方体に内接する立体と体積」（I01〜I06）と「⑨立方体に隠れた図形・長さ・角度」（G01〜G06）を加え、
当初予定していた **全10カテゴリ・75種類**の問題テンプレートがそろいました。立体の形・体積・体積比・長さ・角度・面積は、座標と有理数・√ の正確な計算（Phase 7 の `rational.js`・`surd.js`・体積の関数を再利用）で求め、
問題文・正解・解説・3D をすべて同じ計算結果から作ります。回答後の 3D では、立方体の中に隠れた立体や三角形を、本来の位置のまま目立たせて見せます。
Phase 7・8 で加えた4カテゴリは、通常トレーニング・復習・学習記録・1分チャレンジで遊べます（段位認定は Phase 6 までの6カテゴリのまま。入れるかどうかは Phase 9 で判断）。

Ver.0.10.0 では、新しいゲームモード「トライアル」（4種類から1つを選んで100秒で LEVEL を上げる。数字入力・マス塗り・サイコロの目・展開図の色分け）を加えました（→「トライアル（100秒・LEVEL アップ）」）。
Ver.0.9.1 では、カテゴリを取り組みやすい順（①〜⑩）に並べかえ、タイトル画面に「三平方の定理・√を使う問題」の設定（初期値は出題しない）と、問題画面・あそびかたから開ける「学習ヘルプ」を加えました（→「出題範囲の設定と学習ヘルプ」）。

- 技術：HTML / CSS / JavaScript（ES Modules）、Vite、Three.js（OrbitControls・Raycaster・CSS2DRenderer）、Vitest
- サーバー・データベース不要の静的サイト（GitHub Pages で公開）
- UI フレームワーク・TypeScript は不使用。外部 CDN にも依存しません

## 動作環境

- Node.js 22.12 以上（推奨：24 LTS。`.nvmrc` 参照）
- WebGL2 に対応したブラウザ（Chrome / Edge / Safari / Firefox の最新版）
  - WebGL2 が使えない端末でも、トレーニングは問題文・図・選択肢だけで回答できます

### ドリルモード（旧「トレーニング」）

画面の名前は「ドリルモード」です（Ver.0.10.0 で「トレーニング」から変更。プログラムの中の名前・保存データのキーは `training` のまま）。この README では、以前からの説明で「トレーニング」とも書いています。

1. **カテゴリ選択**：10 カテゴリを名前だけの小さなボタンで表示。10 カテゴリすべて遊べます（①立方体の個数・着色 ②サイコロ・回転 ③積み木の見え方・投影図 ④展開図パズル ⑤展開図と頂点・辺 ⑥立方体の切断 ⑦位置関係 ⑧立方体に内接する立体と体積 ⑨立方体に隠れた図形・長さ・角度 ⑩立方体の表面の最短経路）。
   番号はボタンと説明に表示します（`categoryNumber`）。並び順は `questionRegistry.js` の `CATEGORIES` の順で、カテゴリ ID・テンプレート ID・保存データのキーは変えていません。
   ボタンを押すと、画面下（固定）に説明と「次へ」が出ます（対象学年は表示しません）。右上の「学習記録」で記録を見られます
2. **設定**：難易度（基本／標準／応用／すべて。初期値は基本）と、出題のしかた（「問題数を選ぶ」「1分チャレンジ」を同じ行に横並び）
   - 問題数を選ぶ：問題数のスライダー（1〜20問。初期値は5問）。タイマーなし
   - 1分チャレンジ：スライダーの代わりに、選んだ難易度の最高記録（「最高記録：7問正解」）を表示。1分間で何問正解できるかに挑戦します。
     不正解（おしいをふくむ）は残り時間 −10秒。カウントダウン・タイマー・答え合わせの間は時間が止まる仕組み・中断の扱いは段位認定と同じで、ヒント・パスはありません。
     結果画面に正解数・自己ベスト更新・回答数・正答率を表示し、間違えた問題を復習できます。最高記録は難易度（基本・標準・応用・すべて）ごとに学習記録へ保存します（通常の累計には入れません）
3. **問題**：問題文を読み、選択肢から答えて「回答する」。「回答する」は問題文の下、「ヒントを見る」の右どなりにあります（ヒントのない1分チャレンジ・段位認定でも同じ位置）。回答すると、同じ位置のボタンが「次の問題へ」（最後の問題では「結果を見る」）に変わります
   - 問題の基準になる辺・面は **オレンジ** で表示され、正解表示中も消えません（位置関係）
   - 位置関係では立方体を自由に回せます（面は半透明で表示。「面を不透明に」で切り替え）。回答は選択肢ボタンで行います
   - サイコロ・積み木・展開図では、答えが見えてしまわないように **回答するまで 3D を表示しません**。
     展開図の問題では、3D の場所に展開図（点・辺・面のラベルつき）を表示し、回答すると 3D の展開図が折りたたまれて立方体になります。
     積み木の問題では、3D の場所に静的な見取図（見る向きを示す赤い矢印つき。矢印の根元が見る人の場所）を表示し、回答すると同じ場所が 3D に切りかわります。
     サイコロの問題文の下には、はじめの向きの見取図（「上・前・右」の向きつき）と回転の手順（番号・矢印・文字）を表示します。
     回答すると、自由に回せる立方体が現れて正解演出が始まります
   - ふつうのサイコロ（向かい合う面の目の和が7）の面は数字ではなく **目（ドット）** で表示します（1の目は大きな赤い目）。
     和が7ではない配置のサイコロは、目の代わりに **マーク（〇◎×●◇◆）** で表示します。答えの選択肢も面の絵で表示します
   - 図を選ぶ問題では、選択肢に見取図や面の図（ア〜エ）を表示します
   - 選択肢がふつうはランダムな順に並びますが、図の中の記号（展開図のマス「ア」「イ」…など）を答える問題では、ア・イ・ウ…の順に並べます（トレーニング・1分チャレンジ・段位認定で共通。`shuffleChoices`）
   - 「すべて選ぼう」の問題はチェック形式、「1つ選ぼう」の問題はラジオ形式
   - **ヒント**：回答前に「ヒントを見る」で、考え方の手がかりを表示します（答えは出しません。何度見ても同じ内容）。
     ヒントを使っても正誤判定・正答率は変わりません（使ったかどうかは学習記録に残します）
   - 小立方体の問題では、3D の場所に静的な見取図（分割線・色を塗った面・取り除いた小立方体の赤い点線）を表示し、回答すると 3D に切りかわります
   - 積み木の個数の問題では、3D の場所に積み木の見取図（B12 は「今の形 → 完成形」の2つ）を表示します
4. **解答・解説**：「正解！」「おしい！」「不正解」と解説を表示
   - 解説の中の分数（1/2・9√3/2 など）は、横線の上に分子・下に分母がある縦型の分数で表示します（`ui/mathText.js`。読み上げでは「1/2」）
   - 3D では、誤って選んだ要素が **赤**、正解の要素が **緑** で1つずつ光ります
   - サイコロでは立方体が実際に回転し、積み木ではカメラが矢印の方向（正面・右・真上など）へ移動して答えを確かめられます
   - 回答すると「○」「△」「×」が効果音とともに約1秒大きく出て、そのあと解説を表示します（タップですぐ閉じる）
   - 小立方体では、境界線が現れて小立方体に分かれ、少しはなれてから、条件に合う小立方体が緑の輪郭（ほかは半透明）で光り、個数を表示します。
     「元に戻す」「分離して見る」で切りかえられます
   - 積み木の個数では、積み木が下の段から順に持ち上がって段ごとに分かれ、各段の個数（「1段目 6個」）と合計を表示します。
     見えない積み木は、ほかを半透明にして色付きで示します。指定した段は緑で持ち上げて1個ずつ数え、完成形の問題では加える積み木が1つずつ置かれます
   - 3D の下の「もう一度見る」でリプレイできます（「スキップ」ボタンはありません）。段ごとの個数・合計・面積・体積・道のりなどの文字は、図に重ならないように 3D の右上に縦に並べて表示し、「図のみ表示」で隠せます（もう一度押すと「文字も表示」）。「図のみ表示」では、頂点の記号（A〜H）・点の記号（P・Q・R など）も隠します。頂点・点の記号が出る問題では、回答後にいつもこのボタンを出します
   - 「おしい！」は正解・不正解のちがいが1つだけのとき。正答率には完全正解だけを数えます
5. **結果**（見出しは「ドリルモードの結果」）：正解数・正答率・カテゴリ・難易度。その下に「もう一度挑戦」「設定を変更」「カテゴリ選択」「タイトルへ」（2行×2列）、「第◯問」のカード、「間違えた問題を復習」
   - 「やめる」は確認のうえ、回答済みの分の結果を表示します
   - 「第◯問」のカードを押すと、その問題を1問だけ解き直せます
6. **復習**：「間違えた問題を復習（N問）」で、不正解・おしいだった問題を **同じ問題（同じ図・条件・正解・選択肢の並び）** のまま解き直します（0問ならボタンを出しません）
   - 終わると「復習の結果」（復習した問題数・正解できた数・復習の正答率）を表示。まだ間違えている問題があれば、続けて復習できます
   - 復習の結果は、もとのトレーニングの結果（正解数・正答率・学習記録の累計）には入れません
7. **学習記録**：カテゴリ別に累計問題数・累計正解数・正答率・練習回数・ヒントの回数・難易度別の正答率・最近の結果・復習待ちの問題数を表示します
   - 未プレイのカテゴリは「まだ記録がありません」
   - 間違えた問題はブラウザに保存され、後日「復習する」で同じ問題を復習できます（正しく解けた問題は復習待ちから外れます）
   - 「学習記録を消去」（学習記録画面・あそびかた）で、確認のうえ CUBE MASTER の保存データだけを消せます

### 3つのプレイ形式

| プレイ形式 | 入り口 | 特徴 | 上の帯の表示 |
|---|---|---|---|
| ドリルモード | ドリルモード → 設定で「問題数を選ぶ」 | 問題数を選ぶ・時間制限なし・ヒントあり・解説と3Dを自由に見直せる | 「ドリルモード」 |
| 1分チャレンジ | ドリルモード → 設定で「1分チャレンジ」 | 1カテゴリ・60秒・正解数を競う・不正解 −10秒・ヒントとパスなし | 「1分チャレンジ・基本」など |
| 段位認定 | トップの「段位認定」 | 6カテゴリ混合・100秒・得点で段位・パスあり | 「段位認定・スタンダード」など |

- 設定画面の「問題数を選ぶ」は「時間を気にせず、じっくり練習！」、「1分チャレンジ」は「60秒で何問正解できるか挑戦！」と表示します
- 1分チャレンジ・段位認定は同じ時間制の画面（`ui/timedPlayScreen.js`）で、カウントダウン・タイマー・答え合わせの間の停止・自動で次の問題へ・ロスタイム・中断の扱いがそろっています（トライアルも同じ）。
- **ロスタイム**（トライアル・1分チャレンジ・段位認定の共通ルール。`overtimeMs: 15000`）：残り0秒になってもすぐには終わらず、そのとき解いている問題が「最終問題」になります。残り5秒のカウントダウンと同じ図の左上に「最終問題」と出します（最終問題はパスできない）。答えたら正解でも不正解でも、「○×」のあとすぐに結果画面へ。答えないまま回答できる時間で15秒たつと、画面中央に大きく「時間切れ」を1秒出してから結果画面へ進みます。1分チャレンジの誤答（−10秒）・段位認定のパスで残り0秒になったときは、その時点で「時間切れ」を出して終了します。
  時間切れの瞬間に、選択肢・「回答する」・「パス」を押せなくします
- 演出の速さは `src/core/revealSettings.js` で一元管理します（トレーニング：ふつうの速さ・「○△×」約1秒／時間制の2モード：2.5倍速・長くても約3.2秒で最終状態・「○△×」約0.5秒）。
  どの演出も途中の動きは省きません（時間制の2モードでは、長い演出は時間がたつと最終状態にして次の問題へ進みます）。演出の間はタイマーが止まるので、演出の長さで考える時間は変わりません

### 出題範囲の設定（三平方の定理・√を使う問題）

- タイトル画面の「あそびかた」の下に「三平方の定理・√を使う問題」の設定があります：**出題しない（おすすめ・初期値）**／出題する。
  ボタンの下には説明文を出さず、説明と注意書きは「？」で開きます。設定は `cubeMaster:settings` の `allowPythagoreanQuestions` に保存します（古い保存データに項目がなければ「出題しない」）
- 設定を使うのは**通常トレーニングだけ**です。**1分チャレンジ・段位認定では、設定にかかわらず出題しません**（限られた時間で、計算の量によって有利・不利が出ないようにするため）
- 設定はプレイを始めたときの値で固定し、変えると次のプレイから使われます。復習は、一度出題した問題をそのまま解き直すので判定しません
- 判定は難易度ではなく、問題ごとの前提知識 `prerequisites`（`src/core/learningPrerequisites.js`）で行います（`src/core/questionEligibility.js`）。
  対象は `pythagorean`（三平方の定理）・`squareRoot`（√）だけで、角柱・角錐の体積・立体の名前・正多面体・ねじれの位置は対象にしません（学習ヘルプで確かめられます）
- 対象のテンプレート：

| テンプレート | 扱い（出題しないとき） |
|---|---|
| G03（線分の長さ）・S03（最短経路の長さ） | いつも √ を使うので、候補から外す（`advanced: 'always'`） |
| K05（切り口の面積） | 辺の長さと面積が整数になる切り口だけ |
| G04（三角形の形）・G05（角の大きさ） | 立方体の頂点だけでできる三角形・角（辺・面の対角線・立体の対角線の組み合わせで判断できるもの） |
| G06（三角形の面積） | 直角をはさむ2辺が整数の長さの直角三角形だけ |
| S02（2つの道の比較） | 同じ面の並びの「まっすぐな道と折れた道」、または立方体の対称で重なる道どうし |
| S05（最短経路が通る点） | 面の中心を通る場合だけ |
| S06（最短経路を選ぶ） | 立方体の対称で長さが同じとわかる道と、まっすぐかどうかで比べられる道 |

- 数を答える問題では、答えが √ をふくまない数なら、まちがいの選択肢にも √ を入れません（`surdChoices`。K05・G06・S05 など）。解説の補足（切り口の辺の長さなど）には √ が出ることがあります
- 同じテンプレートでも、√ が要る問題と要らない問題を問題ごとに区別します（`advanced: 'sometimes'`。`bases(ctx)`・`build(base, rng, ctx)` に `ctx.allowAdvanced` を渡す）。
  `QuestionPicker` は条件に合わない問題になったら作り直し（上限 30 回）、それでも作れなければ `NoEligibleQuestionError` を出します（無限に作り直さない）。
  トレーニングの設定画面では、このとき「出題できる問題がありません」と案内し、難易度や設定を勝手に変えません（現在はどのカテゴリ・難易度でも問題があります）
- 1分チャレンジ・段位認定は、問題を作り直しても時間が減りません（タイマーは出題中は止まっています）。記録のキー・得点・段位の基準・`rulesVersion`（3）・段位認定の6カテゴリは変えていません

### 学習ヘルプ

- 問題を解くのに使うけれど、まだ習っていないかもしれない知識を、短い説明と図（SVG）で確かめられます（`src/core/learningHelp.js`・`src/ui/learningHelpVisuals.js`）

| 項目 | 内容 |
|---|---|
| 角柱の体積の求め方 | 体積＝底面積×高さ（底面を青、高さをオレンジで示す図） |
| 三角錐・四角錐の体積 | 体積＝底面積×高さ÷3（高さとななめの辺のちがい、角柱の3分の1） |
| いろいろな立体 | 角柱・角錐・四面体・六面体・八面体（三角錐＝四面体は同じ立体のべつの呼び方） |
| 正多面体とは？ | 正四面体・立方体（正六面体）・正八面体（全部で5種類） |

#### 問題の作り方と判定（`src/core/trial/`。DOM・Three.js 非依存）

- ①：`core/blockGeometry` の高さマップで作り、見取図だけで個数がただ1つに決まる配置だけを出題します（`isCountDeterminedLarge`：浮きがない・どの柱の上の面も見える・
  上の面が見取図の同じ位置に描かれない。見る向き (4,5,6) の整数倍のずれは、横5以上・奥行き7以上・高さ5以上が同時にそろわないと起こらない）。答えは小立方体の数
- ②：投影図は `core/blockProjection`（見た人にとっての左右）。マス目は、前・右は最大の高さの行（最下段が床）、上は奥行きの行（最下段が手前）、横は形のはば＋2列。
  **判定は左右の平行移動だけを許します**（塗ったマスと正解の形を、左右の位置を変えながら比べる）。上下の移動・左右反転・上下反転・回転は不正解。
  ★★★ 以上は、手前・右へ低くなる階段から、見取図で読み取れる範囲で柱を高く・低く・なくして凹みや段差をつくります
- ③：ふつうのサイコロ（向かい合う面の和が7）を24通りのどれかの向きに置き、見えている上・前・右の目から6面すべてが決まります。
  道はとなりのマスへの移動だけ（1回が90°の転がり。`core/cubeRotations` の right・left・forward・backward）で、同じマスを通らず、続いていないマスどうしがとなり合わず（道の順がひと目でわかる）、見取図でサイコロに隠れるマスがない道だけ。答えは `rotateOrientationSequence` で求めた最後の上の面の目
- ④：11種類の展開図（`core/cubeNetCatalog`）を回す・裏返して、辺で接するようにつなげます（難しいほど多くの辺で接する置き方）。
  **お手本と同じでなくても**、全マスがぬられ・色の数が展開図の数と同じで・どの色もちょうど6マス・辺でつながり・折ると立方体になる（`core/cubeNetFolding` の `foldNet`）なら正解です。色の番号は関係ありません

#### 答え合わせの演出（正解・不正解のどちらでも）

- ①：問題画面と同じ 3D（`cubeViewer`）で、少し回して見えない積み木を色付きで示し、段ごとに分けて各段の個数と合計
- ②：3D の積み木へカメラが指定の方向から真正面に回る。マス目には、合っている（緑）・足りない（うすい緑の点線）・よけいな（赤）マスを、左右にずれた位置に合わせて示す
- ③：道の上で今いるマスを順に示しながら、3D のサイコロが同じ手順で転がる（最後の向きは数学の結果と一致。テストで確認）
- ④：`three/trial/trialNetViewer.js`（展開図ごとに `cubeNetModel` を使い、大きさ・位置を変えない `noFit`）で、展開図が少しはなれる → それぞれ折りたたむ → 立方体を横に並べる。
  正解ならプレイヤーのぬり分け、不正解なら入力を少し見せてからお手本の分け方で折りたたむ

### 効果音の設定

- トップ画面の右上の小さなスピーカーのアイコン（押すとオン／オフ）と、あそびかたの「記録と設定」タブで、オン／オフと音量（0〜10）を変えられます。設定はブラウザに保存します（キー `cubeMaster:settings`）
- ボタンを押すと「ポッ」という低く短い音が鳴ります（`installButtonSound`。無効なボタンと、すぐあとに正誤の音が鳴る「回答する」では鳴りません。「次の問題へ」などでは鳴ります）
- トップ画面のメニューは3行（トライアル（横いっぱい）／ドリルモード・段位認定／3D立方体をためす・あそびかた）（上の3つは文字を少し大きく）で、上部の立方体は水平にゆっくり回り続け（押さえると止まる・右へスワイプで速く・左へスワイプで逆向き。`core/spinModel.js`・`ui/homeCube.js`）、いちばん下に小さく著作権表示「©2026 T.TAKEMOTO / KEC Glows」を入れています
- オフのときは何も鳴らしません。効果音がなくても、○△×・色・文字で正誤と結果がわかります。Web Audio が使えないブラウザでも、そのまま遊べます

### 段位認定（100秒）

「100秒で何問解ける？立方体マスターを目指せ！」。トレーニングで習得した力を、短い時間で試すゲームモードです。

| 項目 | トレーニング | 段位認定 |
|---|---|---|
| 制限時間 | なし | 100秒（回答できる時間だけ数える） |
| 出題 | カテゴリ別 | 6カテゴリを混ぜて出題 |
| 難易度 | 自由に選ぶ | レベルごとに決まっている |
| ヒント・もう一度見る | あり | なし |
| 解説・3D 演出 | じっくり | 短く・速く再生して自動で次の問題へ |
| 成績 | 正答率 | スコア・段位（レベル別） |

1. **レベル選択**：ベーシック（★1）・スタンダード（★1 約30%・★2 約70%）・エキスパート（★2 約30%・★3 約70%）。レベルのボタンのすぐ下に「スタート」
2. **3・2・1・START!**：表示に合わせて効果音（3・2・1 はピッ、START! はピーン）。この間は問題が見えないように画面全体をおおい、タイマーは動きません
3. **100秒チャレンジ**：画面の上にタイマー（「72.4秒」）・得点・連続正解数を表示。残り10秒で色が変わり、残り5秒でカウントダウン（図をなるべく隠さないように、図の左上に小さく数字を出す）
   - 回答を確定するとタイマーが止まり、「○△×」（約0.5秒）→ 正誤と得点（「+160点」「−50点」「残り時間 +3秒」）→ 3D 演出（2.5倍速。途中の動きは省かない。長くても約3秒で最終状態）→ 自動で次の問題へ。
     次の問題が表示されて回答できるようになった時点でタイマーが再開します（「次の問題へ」で早く進むこともできます）
   - **パス**：「回答する」と同じ行の左の「パス」で問題を入れかえられます。「問題を入れかえますか？ ペナルティ：残り時間 −○秒」の確認で「はい」を押すと次の問題へ。
     n 回目のパスで残り時間が 2×n 秒へります（確認の表示中も時間は減り続ける）。パスは回答の数・正答率に入らず、減点もしませんが、連続正解ボーナスは0に戻ります
   - ヒント・もう一度見る・展開図に戻すなどの自由な観察はできません。くわしい解説は結果画面から復習できます
   - 0秒になると、そのときの問題が「最終問題」（ロスタイム15秒）。答えたら（正解でも不正解でも）結果発表へ、答えないまま15秒たつと「時間切れ」。そのとき回答中だった問題は未回答（正解にも不正解にも数えない）。ロスタイムも過ぎてから確定した回答は数えません
4. **結果発表**（「時間切れ」はプレイ画面の最後にだけ出し、結果画面には出さない）：得点のカウントアップ → 正解数・正答率・最大連続正解・誤答の減点・多答問題ボーナス・パスの回数・平均解答時間・カテゴリ別の正解数 → 段位（「五段＋ 認定！」「十段★ 達成！」）。
   最高段位が上がったときだけ昇段の演出（初段・十段・皆伝は少し豪華に）。最高得点の更新は「自己ベスト更新！」。画面をタップすると演出をとばせます。
   「正解数」のすぐ上に「もう一度挑戦」「レベルを変更」「記録を見る」「タイトルへ」（2行×2列）。下に「間違えた問題を復習」（トレーニングと同じ画面でじっくり解き直す）
5. **中断**：「やめる」・ほかのタブへの切りかえ・画面を離れる（戻る操作など）と中断になり、記録に残りません（同じ挑戦は再開できません）

#### スコアと段位（`src/core/certificationRules.js` で一元管理）

- 完全正解：★1 100点・★2 160点・★3 240点
- 誤答（不正解・部分正解）は減点：n 回目の誤答で 50×n 点（n は6まで。1回目 50点・2回目 100点…6回目以降 300点）。まちがえるほど重くなります。得点は0点より下がりません。残り時間は減りません
- 答えが複数ある問題（多答問題）に一発で正解すると、残り時間が +3秒
- 連続正解ボーナス：3〜4問連続は1問につき +20点、5問以上は +40点。不正解・部分正解で連続は0に戻る
- 段位は 21 段階（10級 → … → 1級 → 初段 → 二段 → … → 十段 → 皆伝）。内部では 1〜21 の整数（`rankLevel`。0 は認定なし）で、数が大きいほど上位
- 表記はレベルごとに、ベーシックは段位名のみ（五段）、スタンダードは「＋」（五段＋）、エキスパートは「★」（五段★）を直後に付けます（皆伝・皆伝＋・皆伝★）
- 必要スコア（仮の基準。プレイテストのあとに調整する）。ベーシック・スタンダード・エキスパートで共通、2500点で最高段位（皆伝）

| 段位 | 必要スコア |
|---|---:|
| 10級〜1級 | 100〜1,000（100点ごと） |
| 初段・二段・三段 | 1,100・1,200・1,300 |
| 四段〜十段 | 1,450〜2,350（150点ごと） |
| 皆伝 | 2,500 |

  （21段階すべての値は `certificationRules.js`。今の基準は `rulesVersion: 3`）
- 基準を変えるときは `CERTIFICATION_RULES.rulesVersion` を上げます。記録は基準ごとに分けられ、前の基準の最高記録は「前の基準での最高記録」として残ります
- 問題ごとの考える時間の目安（`recommendedSeconds`）・段位認定で出さないテンプレート（`excludedTemplates`）・出題するカテゴリ（`categories`）も同じ設定で変えられます

#### 出題と 100 秒タイマー

- 出題（`src/core/certificationSession.js`）：カテゴリ × 難易度ごとに既存の `QuestionPicker` を使うので、問題の生成と数学的な確かめはトレーニングと同じです。
  カテゴリはなるべく均等に（出題の少ないカテゴリから）、同じカテゴリは3問以上続けず、同じテンプレートも続けません。難易度はレベルの割合に近くなるように選びます。
  問題を作れなかったときは、ほかのカテゴリで作り直します（タイマーは止まっているので時間は減りません）
- タイマー（`src/core/certificationTimer.js`）：`performance.now()` の差から「回答できた時間」だけを足していきます。画面の表示は0.1秒ごとに更新するだけで、時間の計算には使いません。

## 切断・最短経路の数学エンジン（Phase 7）

- **正確な数**（`src/core/rational.js`・`src/core/surd.js`）：立方体の頂点・辺の中点・面の中心はどれも整数の座標なので、
  平面と辺の交点・広げた図の座標は有理数（`Q`）で誤差なく求まります。長さ・面積は「有理数の平方根」（`Surd`：c√r）、道の長さは √ の和（`SurdSum`）で表し、
  √8 と 2√2 を同じ数として扱います（小数の比較だけにたよらない）
- **切断**（`src/core/cubeCutting.js`）：`planeFromThreePoints`（3点が一直線上なら null）・`intersectPlaneWithSegment`・`intersectPlaneWithCube`（12本の辺との交点・同じ点をまとめる・一周する順に並べる）・
  `classifySectionPolygon`・`calculateSectionArea`・`splitCubeByPlane`（6つの面を平面で切り取り、切り口を加えた2つの凸多面体）・`polyhedronVolume`・`classifyPiece`。
  テストで、すべての3点の組の切り口が「同じ平面の上・立方体の表面の上・凸で自己交差なし・3〜6角形」、2つの立体の体積の和が立方体の体積になることを確かめています
- **部分展開**（`src/core/cubeSurfaceUnfolding.js`）：面の並びを、共通の辺を軸に 90° ずつ回して、はじめの面の平面に広げる（6面全体の展開図とは別の、面の一部だけの展開）
- **最短経路**（`src/core/cubeSurfacePath.js`）：`enumerateFacePaths`（同じ面を2回通らない並び）→ `unfoldFaces` → `validateUnfoldedPath`（直線が並びの順に、共通の辺の内側を横切るときだけ道として成り立つ）→
  `findShortestSurfacePaths`（成り立つ道の長さを正確に比べ、同じ長さの最短経路をすべて返す）。テストで、2面の道の長さを小数で細かく調べた最小値と一致すること、立方体を回転しても長さ・本数が変わらないことを確かめています
- **3D**（`src/three/cubeCuttingModel.js`・`surfacePathModel.js`、演出は `cubeCuttingAnimations.js`・`surfacePathAnimations.js`）：数学エンジンの座標をそのまま使って描きます。
  面を広げる回転は `unfoldFaces` と同じ軸・同じ向きなので、広げきったときの形は数学の展開と一致し、道が一直線になります（テストで確認）
- **図**（`src/ui/cuttingVisuals.js`・`surfacePathVisuals.js`）：切り口の形（`section`）と、一部の面を広げた図と道（`pathNet`）の SVG

## 展開図の数学エンジン

### 回転の定義（`src/core/cubeRotations.js`）

| ID | 言い方 | 動き |
|---|---|---|
| `right` | 右へ転がす | 元の上面が右側面になる |
| `left` | 左へ転がす | 元の上面が左側面になる |
| `forward` | 前（手前）へ転がす | 元の上面が前面になる（手前 = +Z） |
| `backward` | 後ろ（奥）へ転がす | 元の上面が後面になる |
| `turnRight` | 水平に右へ回す | 元の前面が右側面になる（上下は変わらない） |
| `turnLeft` | 水平に左へ回す | 元の前面が左側面になる |

回転は成分が -1・0・1 の整数行列で計算するので、何回回しても誤差がたまりません。
立方体の向き（`{ top: 'ABCD', front: 'ABFE', … }`）は 24 通りで、面 ID は回転しても変わりません（変わるのは各面が向いている方向）。
カメラの回転（観察の視点）と、立方体そのものの回転は別々に管理しています。

## 座標系と立方体の定義

Three.js の右手系。X = 左右、Y = 上下、Z = 奥行き（+Z が手前）。中心は原点、一辺は 2。

| 頂点 | 座標 | | 頂点 | 座標 |
|---|---|---|---|---|
| A | (-1, +1, +1) | | E | (-1, -1, +1) |
| B | (+1, +1, +1) | | F | (+1, -1, +1) |
| C | (+1, +1, -1) | | G | (+1, -1, -1) |
| D | (-1, +1, -1) | | H | (-1, -1, -1) |

上面が ABCD、底面が EFGH（A の真下が E、B の真下が F、C の真下が G、D の真下が H）。

- 辺（12）：AB, BC, CD, DA, EF, FG, GH, HE, AE, BF, CG, DH
- 面（6）：ABCD(+Y・上), EFGH(-Y・下), ABFE(+Z・前), BCGF(+X・右), CDHG(-Z・後ろ), DAEH(-X・左)

ID は表記ゆれを正規化して扱います（`"BA"` → 辺 `AB`、`"FGCB"` → 面 `BCGF`）。
存在しない ID（`"AC"` など）は `CubeElementError` になります。

- **実機・ブラウザでの確認**：Chrome・Edge・Android Chrome・iPhone Safari・iPad Safari の実機での動作は **未検証** です（上の手動確認項目を実機で確認してください）。
  Phase 7・8 では、PC の Edge（ヘッドレス・ソフトウェア描画）で、切断・最短経路・内接立体・長さと角度の 3D（回答前・演出の途中・最終状態）と、K03・S04 の図の選択肢を画像にして確かめました。
  問題画面全体の操作（タップ・スクロール・スマホの画面の大きさ）は確かめていません
- **新カテゴリの難易度・時間**：K01〜K06・S01〜S06・I01〜I06・G01〜G06 の難易度・解く時間は、プレイテストで確かめていません。1分チャレンジでは、時間がかかりすぎるテンプレートを `CHALLENGE_RULES.excludedTemplates` で外せます（今は外していません）。
  段位認定には入れていません（`CERTIFICATION_RULES.categories` は Phase 6 のまま。ルール・`rulesVersion: 3` も変えていません）。
  I02（正八面体）・I04（体積比）は答えが毎回同じです（選択肢・向きを変える）
- **問題を作る時間**：切断は3点の組み合わせ（816通り）、最短経路は点の組の計算を、はじめて出題するときに一度だけ行います（PC で 0.1〜0.5 秒ほど）。S04 は1問 50ms ほどかかります。

- **メモリ・描画**：画面を移るたびに 3D を作り直し、そのたびに WebGL のコンテキストを返すようにしました（`renderer.forceContextLoss`）。描画は必要なときだけ行い（`requestRender`）、

- **難易度・配点・段位基準**：仕様どおり、推測では変えていません。実際の生徒の解答時間・得点分布が集まってから調整します（変えるときは `rulesVersion` を上げる）
- **アニメーション軽減**：OS の「視差効果を減らす」設定では、○△×・昇段などの画面の動きを止めます。3D の演出は短縮再生のまま（軽減設定での 3D の扱いは未対応）

## GitHub Pages への公開

`main` ブランチに push すると GitHub Actions（`.github/workflows/deploy.yml`）が
`npm ci → npm run test → npm run build → dist を公開` を実行します。テストかビルドが失敗すると公開されません。
Actions 画面の「Run workflow」から手動実行もできます。

初回のみ、GitHub のリポジトリで **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください（設定済み）。

リポジトリ名を変える場合、ワークフローはリポジトリ名から base パスを自動設定します。

## 後続 Phase で使う API

### 問題データの形（カテゴリ共通。`src/core/questionSchema.js`）

```js
{
  id, templateId: 'P01', key: 'P01:AB', category: 'position', difficulty: 1, type: 'multiple',
  question: '辺ABと平行な辺をすべて選びなさい。',
  scene: { model: 'cube', referenceElements: ['AB'], cameraPreset: 'default' },
  choices: [{ id: 'CD', label: '辺CD', elementId: 'CD' }, { id: 'none', label: 'あてはまる面はない', fixed: true }],
  correctAnswers: ['CD', 'EF', 'GH'],
  explanation: { text: '…', highlightElements: ['CD', 'EF', 'GH'], animation: 'highlightElements' },
}
```

- 選択肢の `id` は任意の文字列（サイコロの目・形の名前・分数などでもよい）。正誤は選択肢 ID の集合で比較する
- `elementId` は 3D 上で対応する要素（誤選択を赤く表示するのに使う）。文章の選択肢では省略
- `fixed: true` の選択肢はシャッフルせず末尾に置く
- Phase 2 で追加（省略可）：`scene.model`（`'cube'`・`'dice'`・`'colorCube'`）、`scene.faces`（面 ID → 装飾）、
  `scene.orientation`（はじめの向き）、`scene.showLabels`、`scene.interaction`（回答前後の回転・ズームの可否）、
  `visuals`（問題の図）、`choices[].visual`（選択肢の図）、`choices[].labelByPosition`（ア〜エを並び順で付ける）、
  `explanation.reveal.steps`（`{ type: 'rotate', moves }`・`{ type: 'camera', direction }`・`{ type: 'pause', ms }`）
- Phase 4 で追加（積み木の個数）：`scene.counting`、図の種類 `blocksPair`（`items`。`fitTo` で2つの図の小立方体を同じ大きさに）、
  演出 `{ type: 'countLayers', hidden }`・`{ type: 'countLayer', level, cubes }`・`{ type: 'addBlocks', cubes }`
- Phase 4 で追加：`scene.model: 'subcubes'`・`scene.subcubes`（`{ divisions, paintedFaces, removed }`）、図の種類 `subcubes`、
  演出 `{ type: 'divide' }`・`{ type: 'separate', to }`・`{ type: 'highlightSubcubes', cubes, label }`、`hint: { text }`、`QUESTION_SCHEMA_VERSION`
- Phase 3 で追加：`scene.model: 'net'`・`scene.net`（3D で折りたたむ展開図）・`scene.preview`（回答前に 3D の場所へ出す図）、
  図の種類 `net`、演出 `{ type: 'fold', to }`、`{ type: 'highlightBlocks', cubes }`、解説の `〔choice:ID〕`

s.checkTimeUp(); s.abort(); s.finish(); s.getSummary(); // { score, correctCount, answeredCount, accuracy, maxStreak, averageAnswerMs, byCategory, rankLevel, aborted }

## 今後の拡張方針

- **新しいカテゴリ**：`src/questions/<category>/` にテンプレートを作り、`questionRegistry.js` の `CATEGORIES` で
  `templates` を設定して `enabled: true` にする。問題画面・エンジン・判定はそのまま使える
- **3D をタップして回答**：`AnswerSelection.toggle(id)` を `viewer.events.on('selection:change')` から呼べば、
  選択肢ボタンと同じ回答状態を共有できる（選択肢 ID に要素 ID を使う問題）
- **展開図・切断**など新しい 3D オブジェクトが必要になったら、`cubeModel` とは別のモジュールで生成し、
  数学データは `core` に置く。問題データの `scene.model` に新しいモデル名を追加する
- **展開図のさらなる活用**（Phase 4 以降）：`foldNet` の各マスの座標（`frames`）を使えば、展開図に描いた目・矢印・線が
  組み立て後にどの向きになるかも計算できる（`cubeFaceLabels` の向きの計算と組み合わせる）。展開図エディタやドラッグ操作にも同じデータが使える
- **新しい立体・図形**：切断（Phase 7）・内接立体（Phase 8）と同じく、数学データを `core` に置き、3D モデルを `three` に別モジュールで作る
- 回転アニメーションは `createTurnSequence` / `createQuestionReveal` を使えば、どの問題からでも同じ動きで再生できる
- **Ver.1.0.0 に向けた残課題**
  - 実機（PC の Chrome・Edge、Android、iPhone・iPad の Safari）での総合確認と、長時間プレイでのメモリ・描画の測定
  - プレイテストでの実測（回答数・正答率・平均解答時間・得点分布）と、その結果にもとづく難易度・配点・段位基準の見直し（記録の書き出し・集計のしかたの整備をふくむ）
  - アニメーション軽減設定のときの 3D 演出の扱い、キーボードだけでの操作の確認
  - 全10カテゴリの統合・難易度と解く時間の確認・段位認定に入れるかの判断は Phase 9
- **Phase 9 への引き継ぎ**
  - 段位認定に新しい4カテゴリ（`cubeCutting`・`surfacePath`・`inscribedSolid`・`cubeGeometryChallenge`）を入れるときは `CERTIFICATION_RULES.categories` に加え、時間がかかりすぎるテンプレートを `excludedTemplates` で外し、配点を変えるなら `rulesVersion` を上げる
  - 1分チャレンジで外すテンプレートは `CHALLENGE_RULES.excludedTemplates`（今は空）。どのカテゴリ・難易度にも出題できるテンプレートが1つ以上残るようにする
  - 問題を作る時間：切断（816通り）・最短経路・内接立体・三角形の候補は、はじめて出題するときに一度だけ作る（PC で 0.5 秒ほどまで）。実機で長くかかるなら、候補を小さくするか、前もって作る
  - 3D は `cubeViewer` の `setCutting` `setSurfacePath` `setSolid` `setMetric` と、`createQuestionReveal` の step で増やせる。図の右上の文字は各モデルの `onInfo`、「図のみ表示」は `setFigureOnly`
- **Phase 8 への引き継ぎ（Phase 7 時点）**
  - 体積・長さ・面積は `core/rational.js`（有理数）と `core/surd.js`（√ をふくむ数・√ の和）で正確に計算できる。選択肢の重複判定は `Surd.key()`、表示は `format('cm²')`
  - 多面体の体積は `polyhedronVolume`（面の多角形の一覧）と `tetrahedronVolume`（|det|/6）を `core/cubeCutting.js` から使える。内接立体（正八面体の体積 1/6 など）にもそのまま使える
  - 立方体の表面の点（頂点・辺の中点・面の中心）の呼び方・点が見えるカメラの向き・立方体の回転24通りは `questions/surfacePoints.js`
  - 新しい 3D モデルは、`cubeViewer` に `setXxx(spec)` を足し、`createQuestionReveal` に演出の step を足す（切断・最短経路と同じ形）。問題データは `questionSchema` の `SCENE_MODELS`・`VISUAL_TYPES` と確かめの関数に加える
  - 切断の演出（平面 → 切り口 → 分離）は、内接立体の「取り除く」演出の参考にできる
- **Phase 6 までの引き継ぎ（調整のしかた）**
  - 段位の必要スコア・得点・ペナルティ・演出の速さは仮の値です。小学生・中学生・講師のプレイテストで、100秒間の回答数・正答率・平均解答時間（結果画面と記録に出る）を見て
    `certificationRules.js` を調整し、`rulesVersion` を上げてください（前の基準の記録は分けて残ります。3レベル共通の基準・★3 240点への変更で `rulesVersion` は 3）
  - 時間がかかりすぎるテンプレートは `excludedTemplates` で段位認定から外せます。`recommendedSeconds` に考える時間の目安を書いておくと、調整・分析に使えます
  - 新しいカテゴリを段位認定に入れるときは `CERTIFICATION_RULES.categories` に加えます（トレーニングで遊べるようにしただけでは入りません）
  - オンラインランキング・対戦・アカウント・クラウド共有は未実装（記録はブラウザの中だけ）。記録の形は `certificationRecords.js`（`RECORDS_VERSION`）
  - 問題データの形を互換性のない形に変えたときは `QUESTION_SCHEMA_VERSION` を上げる（保存済みの復習問題は自動で除外される）
- 全10カテゴリ（75テンプレート）は Phase 8 で実装済み。Phase 9 で全体の統合・バランス調整を行う
